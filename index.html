01 Context

Personal finance is scattered across statements, apps and spreadsheets, and most tools only show what already happened rather than helping decide what to do next.

02 Problem

Build something that reads real transaction data, understands it, and turns it into a controller a person can actually act on — not another dashboard to check and ignore.

03 Architecture

A FastAPI backend handles ingestion and a machine‑learning layer for categorisation and forecasting; a lightweight client surfaces the results as clear, specific guidance instead of raw numbers.

04 Implementation

Built in Python end to end — data pipeline, model, and API — with an emphasis on keeping the ML layer replaceable as the categorisation and forecasting approach improves.

05 Result

A working finance controller that turns raw transactions into a running, understandable picture of where money is going — the seed of a system rather than a one‑off script.
