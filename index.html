Featured — 01 · Finance / AI

LEDGR

AI‑powered finance controller

A finance system designed to turn transaction history into useful next steps. Built as a data pipeline, ML layer, and API so the insight can evolve without rebuilding the product.

PythonFastAPIMachine LearningDocker
View source ↗
01 Context

Personal finance is scattered across statements, apps and spreadsheets. Most tools show what happened; LEDGR explores how data can help decide what to do next.

02 Approach

Build a controller that reads transaction data, categorises it, and turns the resulting picture into guidance a person can act on.

03 How it works

A FastAPI backend handles ingestion and a replaceable machine-learning layer supports categorisation and forecasting. A lightweight client presents clear guidance instead of raw numbers.

04 What I learned

The model is only one part of a useful product: data quality, explainable outputs, and the path from insight to action matter just as much.
